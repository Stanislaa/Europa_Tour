# Веб-сайт ООО «Европа-Тур»

Туристическое агентство. Стек: **Python (FastAPI)** + **JavaScript + HTML + CSS**
(SPA без фреймворков) + **PostgreSQL / MySQL / SQLite** + Redis (опционально).

## Структура

```
code/
├── render.yaml          # Blueprint для деплоя на Render
├── docker-compose.yml   # запуск всего стека локально через Docker
├── backend/
│   ├── main.py          # FastAPI: модели, БД, JWT, эндпоинты, раздача сайта
│   ├── seed.py          # тестовые данные (8 стран, 14 туров)
│   ├── schema.sql       # SQL-схема для MySQL
│   ├── requirements.txt
│   └── Dockerfile
└── frontend/
    ├── index.html       # SPA-каркас
    ├── styles.css       # адаптивный дизайн, светлая/тёмная темы
    ├── app.js           # логика клиента
    └── favicon.svg      # иконка сайта
```

Backend сам раздаёт файлы фронтенда, поэтому сайт и API работают как один
сервис по одному адресу — отдельный хостинг для фронтенда не нужен.

## Деплой на Render (Blueprint)

Файл `render.yaml` уже настроен. Render развернёт один веб-сервис
(FastAPI + сайт) и бесплатную базу PostgreSQL.

1. Залейте папку `code/` в репозиторий на GitHub (или GitLab).
   Важно: `render.yaml` должен лежать в корне репозитория.
   Если `code/` — это корень репозитория, всё в порядке.
2. На https://dashboard.render.com нажмите **New → Blueprint**.
3. Подключите репозиторий. Render найдёт `render.yaml` и покажет план:
   веб-сервис `europa-tour` + база `europa-tour-db`.
4. Нажмите **Apply**. Render соберёт проект (несколько минут).
5. База подключается автоматически, секретный ключ генерируется сам,
   тестовые данные загружаются при первом старте.
6. Готово. Сайт будет доступен по адресу вида
   `https://europa-tour.onrender.com` — там и сайт, и API.

Замечания по бесплатному плану Render:
- Сервис «засыпает» после 15 минут простоя; первый запрос после сна
  занимает 30–60 секунд — это нормально.
- Бесплатная база PostgreSQL живёт 30 дней, затем её нужно пересоздать.
- Redis не используется (кеширование просто отключается, сайт работает).

## Запуск через Docker (локально)

```bash
cd code
docker compose up --build
```
- Сайт: http://localhost:8080
- API: http://localhost:8000 (Swagger: http://localhost:8000/docs)

## Локальный запуск без Docker

```bash
cd backend
python -m venv venv && source venv/bin/activate    # Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```
По умолчанию используется SQLite (файл `europa_tour.db`), база наполняется
тестовыми данными автоматически при первом старте.
Сайт и API: http://localhost:8000

## Функционал

- Каталог туров с фильтрами: страна, цена, питание, категория отеля.
- Поиск по названию тура, отеля, города и страны — без учёта регистра,
  работает с кириллицей.
- Сортировка: по цене (возр./убыв.) и по категории отеля.
- Цены показываются за одну ночь на человека.
- Карточка тура с подробной информацией.
- Регистрация с подтверждением email и вход (JWT).
- Бронирование тура с расчётом стоимости.
- Оплата брони (имитация: статус `created → paid`).
- Отмена брони.
- Личный кабинет: статистика, история бронирований, редактирование
  профиля, смена пароля.
- Избранное: добавление/удаление, отметка избранных туров в каталоге.
- Светлая и тёмная темы (переключатель в шапке, выбор сохраняется).
- Адаптивная вёрстка: десктоп, планшет, смартфон, узкие экраны.

## Подтверждение email

В реальной системе ссылка подтверждения отправляется письмом. На демо-стенде
почтовый сервер не подключён, поэтому токен подтверждения возвращается прямо
в ответе `/api/auth/register` и `/api/auth/resend`, а фронтенд показывает
экран подтверждения. Для боевого режима нужно подключить отправку писем (SMTP)
и убрать токен из ответа API.

## Переменные окружения

| Переменная     | Назначение                            | По умолчанию                  |
|----------------|---------------------------------------|-------------------------------|
| `DATABASE_URL` | строка подключения к БД               | `sqlite:///./europa_tour.db`  |
| `REDIS_URL`    | строка подключения к Redis            | `redis://localhost:6379/0`    |
| `SECRET_KEY`   | ключ подписи JWT — **сменить в проде** | `change-me-in-production-please` |
| `AUTO_SEED`    | автозаполнение БД при старте (`1`/`0`) | `1`                           |

Redis необязателен: если он недоступен, сайт работает без кеширования.
URL вида `postgres://...` автоматически приводится к `postgresql://...`.
